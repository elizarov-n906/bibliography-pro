Плагин для управления библиографией и примечаниями в научных статьях WordPress

== Description ==

**Bibliography Pro** — плагин для научных журналов и академических сайтов, позволяющий удобно управлять библиографией и примечаниями в статьях.

= Основные возможности: =

**Библиография (список литературы):**
* Добавление источников литературы к каждой статье
* Вставка ссылок в текст через квадратные скобки [1], [2], [3]
* Нумерация источников
* Изменение порядка (кнопки Вверх/Вниз)
* Активация/деактивация ссылок в тексте источника
* Всплывающее окно при клике на [1] в тексте

**Примечания:**
* Добавление примечаний к статье
* Вставка надстрочных цифр (1, 2, 3) в текст
* Отдельная нумерация примечаний
* Всплывающее окно при клике на надстрочную цифру

**Гибкая настройка:**
* Индивидуальные заголовки блоков для каждой статьи
* Настройка порядка вывода (сначала примечания или сначала библиография)
* Общие настройки по умолчанию для всех статей
* Кастомные CSS стили

**Удобная работа:**
* Кнопки "Добавить 10 строк" для быстрого добавления полей
* Кнопка "Сноска" в панели редактора
* Подсветка при вставке
* Автоматическая нумерация
* Вкладки в админке: Статьи, Все записи, Настройки

**Совместимость:**
* Классический редактор WordPress
* Gutenberg (блочный редактор)
* Кастомные типы записей (при необходимости)

== Installation ==

= Способ 1: Автоматическая установка =

1. Зайдите в админку сайта: Плагины → Добавить новый
2. Нажмите "Загрузить плагин"
3. Выберите файл `bibliography-pro.zip`
4. Нажмите "Установить"
5. Активируйте плагин

= Способ 2: Ручная установка =

1. Распакуйте архив
2. Загрузите папку `bibliography-pro` в `/wp-content/plugins/`
3. Активируйте плагин в админке

= Первый запуск: =

1. Откройте любую статью для редактирования
2. Внизу появится блок "Примечания / Библиография"
3. Добавьте источники литературы и примечания
4. Сохраните статью
5. В тексте используйте кнопки [+] и [прим] для вставки ссылок

== Frequently Asked Questions ==

= Как вставить ссылку на источник в текст? =

1. Поставьте курсор в нужное место текста
2. Нажмите кнопку [+] справа от источника в блоке библиографии
3. В текст вставится [1] (или другой номер)
4. На сайте при клике на [1] откроется всплывающее окно с полным описанием

= Как вставить примечание в текст? =

1. Поставьте курсор в нужное место текста
2. Нажмите кнопку [прим] справа от примечания
3. В текст вставится {note:1}
4. На сайте это будет выглядеть как надстрочная цифра 1

= Как изменить заголовок блока? =

**Для всех статей:**
Библиография → Настройки → Заголовок примечаний / Заголовок библиографии

**Для конкретной статьи:**
Откройте статью → в блоке плагина сверху есть поля для изменения заголовков

= Как изменить порядок вывода на сайте? =

**Для всех статей:**
Библиография → Настройки → Порядок вывода на сайте

**Для конкретной статьи:**
Откройте статью → в блоке плагина выберите порядок радио-кнопками

= Как сделать ссылку в библиографии кликабельной? =

Нажмите кнопку "Ссылка" справа от источника — она станет "Активна" (синей). Все ссылки в тексте источника станут кликабельными.

= Поддерживает ли плагин кастомные типы записей? =

Плагин работает только с типом записи "post" (записи). Для кастомных типов потребуется доработка кода.

= Данные сохранятся при обновлении плагина? =

Да, все данные хранятся в базе данных и не удаляются при обновлении плагина.
